# 第13章 落とし穴とトラブルシュート

**使い方**: 症状から探す。原因は「実際に踏んだもの」を中心に集めた。**まず第0節の切り分けの順**を試し、それでも分からなければ症状表へ。

## 0. 切り分けの順(どの問題でも)

1. **ログを見る**。エンジンは標準出力、Houdini 経由なら `*_video_factory.log`、ブラウザなら DevTools のコンソール。「成功」の通知より**ログが先**。
2. **どの段か**を絞る(第4章の7段)。`metadata.json` の `pipeline[]` に、失敗した段が出る。
3. **`--mock` で再現するか**。再現する → コードの問題。しない → 実データ・ネット・環境の問題。
4. **キャッシュを疑う**(ビルド・ブラウザ・wrangler)。消して再現するか確かめる。
5. **最後に動いた時点との差**(`git log`、`git diff`)を見る。

## 1. 生成(エンジン)

| 症状 | 原因 | 対処 |
|---|---|---|
| 動画の声が機械的 | クラウド音声が失敗して SAPI に落ちた | ログの「どの声を使うか」の行と切り替えの警告を見る。`CLOUD_RAG_URL`/キー、VOICEVOX を確認(第6章) |
| クラウド音声が HTTP エラー | 1日の上限・レート制限・キー違い | 例外文に Worker のエラー文が入る。上限なら翌日か、VOICEVOX へ |
| 通信が弾かれる(403 など) | **User-Agent**が既定のまま(Cloudflare が弾く) | `RAGReel/1.0 (cloud-tts)` のように明示 |
| 動画が異常に長い | 生のコードが読み上げられた(ノード構成セクションなど) | 要約に置き換える(`replaceNodeConfigSection`)。入力のコード量を確認 |
| 図に余計な四角が出る | 出典の印 `[1]` が Mermaid の依頼に混ざった | `stripCitationMarkers` を通す(コードの中には適用しない) |
| 見出しの無い回答が1枚の長いスクロール | 3段階目が効いていない | `splitLongTextSlides` と `kMaxCharsPerSlide`(200) |
| `VP9 encoder not available` | FFmpeg の vcpkg ビルドに `vpx` 機能が無い | `vcpkg.json` で ffmpeg の機能に `vpx` を入れ、作り直す |
| Opus が「実験的」の警告 | `AV_CODEC_ID_OPUS` で探すと内蔵の実験エンコーダになる | 名前 `"libopus"` で探す |
| 進捗(%)が出ない/止まる | ログの文言を変えた(パネルが文言で%を計算) | `Rendered frame N / M`・`Narration progress: k / n`・`Wrote …` を保つ(第2章) |
| 保存で権限エラー | `Program Files` に「すべてのユーザー」でインストールした | 「自分だけ」で `%LOCALAPPDATA%\Programs\RAGReel` へ |
| インストール時のコピー失敗 | インストール先のパスが長い(約250字)。Windows の上限 | 短いパスへ |
| 他のPCで起動しない | Visual C++ ランタイムが無い | インストーラーが同梱(app-local)。同梱ファイルを確認 |

## 2. ビルド

| 症状 | 原因 | 対処 |
|---|---|---|
| 設定が古い、変更が効かない | **CMake のキャッシュ**が古い | `build/` を消して `cmake --preset default` から |
| 新しい `.cpp` が無視される | `CMakeLists.txt` の一覧に足していない | 本体・テストの一覧に足す |
| 配布版にだけ画面が無い | `_dashboard_file` の一覧と `ragreel.iss` に足していない | 両方に足す(レシピ6) |
| `cmd.exe /c` が失敗する | Git Bash(MSYS)がパスや引数を変換する | `cmd.exe //c` とバッチファイルで呼ぶ |
| 初回ビルドが数十分 | vcpkg が Qt6/FFmpeg をソースからビルド | 正常。2回目以降は速い |
| 「成功」と出たのに実行ファイルが古い | 通知だけを信じた/ログに隠れたエラー | **ログの最後まで**読み、クリーンビルド |

## 3. ダッシュボード(Web)

| 症状 | 原因 | 対処 |
|---|---|---|
| 「manifest を読み込めませんでした」 | `file://` では `fetch` が拒否される/`manifest.js` が無い | `.js` ミラーを読む(`loadManifest`)。初回で無い場合は空として扱う(第8章) |
| ES モジュールが動かない | `file://` はモジュールを拒否 | classic script のみ。three.js は r128 の classic ビルド |
| 画面のどこかが `<script>` で動いてしまう | `innerHTML` に未エスケープの文字列 | `escapeHTML`(共有ギャラリーでは他人のタイトルが入る) |
| 「方式の比較」が 404 | ローカルの `output/` には比較ページが無い | ローカルでは出さない(`HAS_COMPARE`)。共有ギャラリーで見る |
| ランディングの3Dディスクが出ない | CDN(three.js)に届かない | CSS の代替(`#heroFallback`)が出る。ネットを確認 |
| 章をクリックしてもシークが遅い | サーバーが Range に対応していない | R2 の `/videos/...` は対応済み。静的アセットの動画は 200 で全体(第9章) |
| カードの先頭が操作できない(スタック表示) | `z-index` が無く、最前面が末尾のカードだった | z-index を計算。リンクのネイティブドラッグを無効(`draggable=false`) |
| 文字が読みにくい | コントラスト不足(薄い灰色など) | `node tools/check_contrast.js`。トークンを調整 |
| ダークだけ色が違う | `[data-theme="dark"]` と `prefers-color-scheme` の**2か所**の値がずれた | 両方を同じに。`check_contrast.js` が DRIFT を検出 |

## 4. 共有ギャラリー(Worker)

| 症状 | 原因 | 対処 |
|---|---|---|
| アップロードが 401 | `UPLOAD_TOKEN` が未設定/不一致 | `wrangler secret put UPLOAD_TOKEN`。エンジン側の `GALLERY_UPLOAD_TOKEN` と同じ値 |
| アップロードが通信エラー(HTTP/2) | Qt の multipart と Cloudflare の HTTP/2 | `Http2AllowedAttribute = false`(実装済み) |
| `wrangler deploy` が拒否 | `compatibility_date` が**未来** | 過去の日付(`2025-01-01`) |
| 一覧が古い/新しい動画が出ない | `/manifest.json` が静的アセットから返った | `run_worker_first` に載っているか |
| 一覧から動画が消えた | 同時アップロードの read-modify-write の衝突 | 逐次に送る(第9章 演習3) |
| 秘密を誤ってコミットした | — | **まず鍵を無効化・再発行**(履歴の書き換えより先)。追跡を外し `.gitignore` へ |

## 5. 比較・図

| 症状 | 原因 | 対処 |
|---|---|---|
| `p=1` で絵が前の絵に1段ずれる(254) | 丸め誤差 | 端点は早期 return、途中は `np.rint` |
| 小さい入力で `BrokenPipe` | エンコーダが途中終了(既存の挙動) | 通常サイズの入力で確認。未確認として記録 |
| 図の文字が重なる | 座標と文字幅 | `tw()` で幅を見積もる/箱を広げる。ブラウザで目視 |

## 6. 「ありがち」な思い込み

- 「ビルドが成功した → 最新が動いている」: **違う**。ログとクリーンビルドで確かめる。
- 「単体テストが通った → 実データでも動く」: **違う**。実データで初めて出る不具合は多い(第11章)。
- 「ネットの送信が失敗した → 動画も失敗」: **違う**。ローカルの公開は先に成功している。
- 「公開リポジトリから消した → もう見えない」: **違う**。履歴に残る。
- 「HTTP 200 が返った → 画面が正しい」: **違う**。目で見る確認は別。

## 演習

1. ギャラリーを開いたら「manifest を読み込めませんでした」と出た。`file://` と https で、それぞれ何を確認するか。
2. 共有ギャラリーに送った動画が、数分後に一覧から消えた。考えられる原因を2つ。
3. ビルドが成功したのに、新しい QML の見た目が出ない。順に何を確かめるか。

## 解答(例)

1. `file://`: `manifest.js` が同じフォルダにあるか・中身が `window.__VF_MANIFEST__ = …` か・DevTools のエラー。https: `/manifest.json` が 200 か・Worker が R2 から返しているか(`run_worker_first`)。
2. (a) 同時に別の動画をアップロードして、manifest の更新が上書きされた。(b) `DELETE` が(別の人から)実行された。R2 の `manifest.json` と `videos/<id>/` を確認する。
3. QML が出力先へコピーされているか(ビルド後のコピー・`CMakeLists.txt` の一覧)→ 古い実行ファイル/古い `qml/` を見ていないか → クリーンビルド → ログ(QML の読み込みエラー)。
