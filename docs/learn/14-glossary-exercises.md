## 14.2 総復習クイズ(各2分)

1. 動画の尺は何から決まるか。
2. RAGReel.exe とエンジンの関係を述べよ。
3. `GpuLease` を取らないと何が起きうるか。
4. 見出しの無い回答でも、スライド形式になる理由は。
5. SAPI の字幕の時刻が「概算」である理由は。
6. `file://` で `fetch` が使えないので何をしたか。
7. `metadata.json` に項目を足すとき、旧い動画のために何をするか。
8. 共有ギャラリーに書き込める人の条件は。
9. Range 非対応だと、章ジャンプはどうなるか。
10. トランジション `p=1` の出力が満たすべき条件は。

### 解答
1. 音声の実測の長さ + 余韻。
2. 設定を集めてエンジンを子プロセスで起動する薄い GUI。生成はエンジンが行う。
3. ナレーションとシーン描画が同時に GPU/VRAM を使い、メモリ不足・競合になりうる。
4. ③の `splitLongTextSlides` が、長い本文を 200 文字ごとに再分割するから。
5. SAPI の同期 API は文ごとの時刻を返さないので、全体の長さを文字数で配分する。
6. `manifest.js`/`metadata.js` のミラーを同時に書き、`<script>` で読む。ES モジュールも使わない。
7. JS 側を「無ければ省略」で書き、C++ は値があるときだけ書く。旧い動画で開いて確かめる。
8. `UPLOAD_TOKEN` を知っている(`Authorization: Bearer` が一致する)こと。読むのは誰でもできる。
9. ブラウザが全体を読み込んでからでないと飛べず、遅い/効かない。
10. `b` と完全一致(丸め誤差なし)。

## 14.3 総合課題(手を動かす)

### 課題A(入門): 読みを1つ足す
`tts_dictionary.json` に自分の好きな専門用語を1件足し、テストを足し、実際に読ませる(レシピ3)。
**合格の目安**: テストが通る/字幕は元の綴り/読ませて聞いた。

### 課題B(標準): ダッシュボードに「章が多い順」の件数バッジを出す
ギャラリーのカードに `chapter_count` を「N 章」と出す(すでに副題に出ている場合は、別の表示を足してよい)。`chapter_count` が無い旧い動画は何も出さない。
**手順の指針**: `gallery.html` の `cardHTML` → `escapeHTML`/数値の書式 → `node tools/check_gallery_layout.js` → `file://` で旧い動画・新しい動画の両方 → ダーク → 「動きを減らす」。
**合格の目安**: 旧い動画で壊れない/色の役割に反しない(情報=青)/検査が通る。

### 課題C(発展): パイプラインに「要約」段を足す
レシピ1に沿って `Summarize` を足し、`metadata.json` の `pipeline[]` と「生成過程」に出す。失敗しても動画は失われない。
**合格の目安**: 単体テスト/`--mock` で通し/旧い動画で壊れない/ドキュメントと図の更新。

### 課題D(発展): 共有ギャラリーに `GET /api/stats` を足す
レシピ7。認証なし・本数と総再生時間を返す。`wrangler dev` でローカル確認 → デプロイ → HTTP で確認。
**合格の目安**: `run_worker_first` の扱いを説明できる/不正な入力に 400/ドキュメント更新。

### 課題E(発展): 新しいトランジション `spiral`
レシピ5。端点が厳密・純関数・3種以内の検証が壊れないこと。目視のコンタクトシートを添える。
