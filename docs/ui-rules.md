# Webダッシュボードの決めごと(UIルール)

作成日: 2026-10-11 / 対象: `web/public/`(`index.html` / `gallery.html` / `video.html` / `random.html` / `404.html` / `styles.css` / `app.js`)
根拠: [IMPROVEMENT_DESIGN_2026-10.md](../IMPROVEMENT_DESIGN_2026-10.md)(P1「決めていないことを無くす」)

骨格(配色・角丸・書体・レイアウト)は変えず、「場所ごとにバラつく」ものを1枚の表で固定する。迷ったらこの表に従い、表に無いものを足すときは先に表へ追記する。

## 1. 決めごと表

| 項目 | 決め |
|---|---|
| アイコン | `app.js` の `ICONS` にある**線画SVG1セット**だけ(線幅2・丸端)。絵文字は見出し・ボタンに使わない。追加するときは同じ線幅で `ICONS` に足す |
| 色の役割 | **オレンジ=主操作 / ミント=完了 / ピンク=エラー・削除 / 青=情報 / 黄=注意 / 紫=RAG出典**。役割以外に使わない(装飾のための色回しをしない) |
| 例外(1つだけ) | 動画詳細の**章タイムライン**は「章ごとに色分け」(U1)のため、6色を章の順に回す。意味は持たせず、章名はツールチップと下の一覧で示す |
| 数字 | 半角。桁が並ぶ所は等幅(全体に `font-variant-numeric: tabular-nums`)。再生時間は `m:ss`、日付は `YYYY/M/D` |
| 矢印 | 開閉は**下向き**(開くと上向き)、遷移は**右向き**。「戻る」だけ左向き |
| 行の構造 | タイトル + 灰色の副題(日付・長さなど)の**2段**。1行に2つの情報を詰めない |
| 余りタイル | 列数は3〜4(幅が足りなければ2→1)。最終段に1個だけ残るときは、その1枚を行いっぱいの横長カードにする |
| 破壊的操作 | 画面の端に分離し、**モーダルで確認**。「共有ギャラリーからの削除」と「PC内ファイルの削除」は文言で区別する(後者はこの画面からは行わない) |
| 動き | **1画面で2種類まで**。通常画面は静か。すべて `prefers-reduced-motion` で止める。モーダル・トーストは動かさない |
| 遊びごころ | `random.html`(ガチャ)、404、空ギャラリーにだけ入れる。空ギャラリーの回転寿司ベルト(`startSushiBelt`)は既存の `-ink` 色だけを使い、`prefers-reduced-motion` では1コマで止め、画面外では描かない |

## 2. 画面ごとの動き(2種類まで)

| 画面 | 使う動き | 使わないもの |
|---|---|---|
| ギャラリー | カウントアップ(ヒーロー数値)、スタッガー(カードの順次表示。初回のみ) | スケルトンのちらつき(静止表示にする) |
| 動画詳細 | アコーディオン(生成過程)、ドロワー(管理) | モーダル・トーストは動かさない |
| ランダム再生 | カードが跳ねる(1種類) | — |
| 404 / 空状態 | 上下にゆれる(1種類) | — |
| ギャラリーの空状態 | 回転寿司ベルト(ASCII の皿が左へ流れる。1種類)+「0本」のゆれ | ベルト以外の動き。本文・操作部品への飾り |

## 3. テーマ

- 既定は `prefers-color-scheme`、右上のトグルで手動切替(`localStorage` の `vf_theme`)。
- ダークの地は青みの無い暖かい炭色。副題の灰色(`--text-3`)はコントラスト4.5:1以上を保つ(`tools/check_contrast.js` で確認できる)。
- `random.html` は元々暗い没入型のため、テーマに関わらず暗いまま。

## 4. 画面に出さないもの(意図的)

- 生成の完了・失敗の**通知**(トースト): このダッシュボードは静的で、実行中の状態を持たない(公開時点で全ステージが終了している)。そのためトーストは操作結果(コピー・削除)にだけ使う。
