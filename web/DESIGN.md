# DESIGN.md — Video Factory(RAGReel の Web ダッシュボード)の見た目の決めごと

新しい画面や部品を足す(AI に頼む場合も)ときは、この文書を渡す。値の出どころは `public/styles.css`(トークン)。食い違ったらコードを正とし、この文書を直す。既存の規則は [docs/ui-rules.md](../docs/ui-rules.md)(線画アイコン 1 セット・色の役割の固定・数字は等幅・1 画面の動きは 2 種類まで)。

背景: [QUALITY_UPLIFT_2026-11-09.md](../../QUALITY_UPLIFT_2026-11-09.md)(QL1〜QL3)。共通の考え方は [Web/Portfolio/DESIGN.md](../../Web/Portfolio/DESIGN.md)。画面は `public/` の素の HTML + JS + CSS(ビルド不要)。**製品の核は動画そのもの**。ギャラリーは、カードの動き 1 つに絞る。

## 1. 方針
- 暖かい紙の地(`--bg`)に、白い面(`--panel`)。差し色は 6 色(オレンジ・ミント・ピンク・青・黄・紫)で、**役割を固定**する(`docs/ui-rules.md`)。
- 色だけで区別しない(アイコン・ラベルを併記)。
- 管理(削除など)は確認ダイアログの 1 か所(`btn-danger`)。画面に重い演出を置かない。

## 2. 書体
システムの書体(`"Yu Gothic UI", "Segoe UI", sans-serif`)。外部のフォントは読まない。

## 3. 色(2 テーマ)
`<html data-theme="light|dark">`(各ページの先頭のインライン script が、保存値 `vf_theme` から描画前に決める)。部品はトークンだけを使い、色を直書きしない。

| トークン | ライト | ダーク | 用途 |
|---|---|---|---|
| `--bg` | `#f6f3ec` | `#1b1916` | 地 |
| `--panel` / `--panel-border` | `#ffffff` / `#eae5d9` | `#252220` / `#38342d` | 面・罫線 |
| `--text-0` / `-1` / `-2` / `-3` | `#1c1c1c` / `#3c3c3c` / `#6b675d` / `#6f6b61` | `#f4efe6` / `#dcd6ca` / `#b8b2a5` / `#9a9487` | 本文 → 補助(3 段階) |
| `--orange` `--mint` `--pink` `--blue` `--yellow` `--purple` | `#ff7a45` `#35c98f` `#ff5d8f` `#4f8dfd` `#f5b400` `#9a6bff` | 同じ(塗り・図形用) | 差し色(塗り) |
| `--orange-ink` `--pink-ink` ほか `*-ink` | `#b8430f` `#b52b57` … | `#ffa27c` `#ff8fb2` … | **差し色の文字**(地の上で読める濃さ) |
| `--on-bright` | `#1c1c1c` | `#1c1c1c` | **明るいオレンジ・ピンクの塗りの上の文字**(どちらのテーマでも暗い) |

**使い分け**: 差し色を**文字・細い線**に使うときは `--*-ink`。**塗り**に使うときは `--orange` など。**塗りの上の文字は `--on-bright`**(白にしない)。

### 3.1 コントラスト(2026-11-11 の実測)
基準: 通常の文字 4.5:1 以上、大きい文字 3:1 以上(WCAG 2.x AA)。`gallery.html`(172 要素)・`index.html`・`compare.html`(124)・`video.html?id=…`(13)・`random.html`・`404.html` の全テキストの実際の色と背景を、ライト・ダークの両方で測った。**基準未満は 0 件**(最小: ライト 4.80:1・ダーク 5.24:1)。

**測定で見つかり、直したもの**
| 問題 | 前 | 後 |
|---|---|---|
| オレンジ / ピンクのボタンの文字(`btn-primary`・`btn-danger`・`stack-toggle.active`・`shuffle-btn.primary`) | 白 → **2.59:1**(ピンクは 2.91:1) | `--on-bright`(`#1c1c1c`)→ 橙で 6.59:1・桃で 5.85:1 |
| 404 の大きな「0」(ライト) | `--orange` → **2.33:1**(大きい文字は 3:1) | `--orange-ink` → 4.92:1 |

**測るときの注意**: 測定中は `transition` / `animation` を止める(途中の色を読んで誤判定するため)。

## 4. 動き
1. **既存の動きは、それぞれの時間を持つ**(約 13 か所)。書き換えない。**これから足す動き**は、`styles.css` のトークンを使う: `--dur-instant` 120ms・`--dur-open` 240ms・`--dur-enter` 300ms、`--ease-out` / `--ease-in` / `--ease-move`。動かす性質は `transform` と `opacity`。**1 画面の動きは 2 種類まで**(`docs/ui-rules.md`)。
2. **動きを減らす**: `prefers-reduced-motion: reduce` で、すべての `animation` / `transition` を止める(末尾の規則)。
3. 無限ループは**ない**。404 の点は 3 回で止まる(**2026-11-11 に、無限から 3 回へ変更**)。**新しい無限ループは足さない**。

## 5. アイコン
- **マーク**: 暗い角丸の正方形に、リール(輪)と、オレンジの再生マーク。1 つの図形から作る。
- **一式(静的ファイル)**: `icon.svg`(ブラウザが暗いときは明暗が反転)・`favicon.ico`(16 / 32 / 48px)・`apple-touch-icon.png`・`icon-192.png` / `icon-512.png`・`site.webmanifest`。全ページの `<head>` にリンクがある。**`manifest.json` は動画の一覧(データ)**なので、PWA のマニフェストは `site.webmanifest`。
- **OGP は作っていない**: 公開 URL(絶対 URL が要る)が決まっていないため。公開先が決まったら、`og:image` を足す。
- **検査**: 16px で輪と再生マークが判別できること(確認済み)。
